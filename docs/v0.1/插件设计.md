# v0.1 插件设计

本文定义 v0.1 每个 `pulse_*` 插件的职责、ECS 组件、系统和依赖关系，内容与当前源码及 IDL 生成的头文件保持一致。

---

## 通用约定

- 所有 `pulse_*` 插件的 C API 公共头文件均通过 IDL（接口定义语言）自动生成，禁止手改。处理流程与语法详见 [`docs/IDL.md`](../IDL.md)。
- 每个插件以 `PulsePluginDesc`（build / post_build / shutdown 三个回调）注册进 App；插件之间通过先决条件（build 期检查、ECS 组件/单例是否就绪）表达依赖。
- 插件注册顺序参考 `examples/snake/main.cpp`：
  `pulse_input` → `pulse_window` → `pulse_asset` → `pulse_transform` → `pulse_graphics` → `pulse_renderer` → `pulse_imgui`（`pulse_daslang` 按需加入）。

---

## 帧管线总览（阶段）

v0.1 使用 flecs 内置 pipeline，阶段为`EcsOnLoad` → `EcsPreUpdate` → `EcsOnUpdate` → `EcsPostUpdate` → `EcsPreStore` → `EcsOnStore` → `EcsPostFrame`，并在其上挂自定义 phase（`PulseCgpuRender*` 链、`PulseImguiPhase`）。每帧顺序：

| 阶段 | 运行内容 |
|------|---------|
| EcsOnLoad | pulse_asset 推进加载队列（AssetProcessSystem） |
| EcsPreUpdate | PulseTimeSystem（PulseTimer）；PulseInputSystem（鼠标 motion 轮询）；PulseImguiDisplaySyncSystem / PulseImguiBeginSystem（ImGui NewFrame，帧窗口打开） |
| EcsOnUpdate | 用户游戏逻辑（C++ 系统，以及 daslang 脚本注册的 `[system]`） |
| EcsPostUpdate | pulse_transform：EnsureWorldTransform → PropagateWorldTransform；pulse_renderer：ExtractCameras → CollectRenderables → SortAndPack → PacketsSwap |
| PulseImguiPhase | 用户 ImGui 绘制 system（可选的专用阶段，DependsOn EcsPostUpdate） |
| EcsPreStore | PulseImguiEndSystem（ImGui::Render 收帧） |
| EcsOnStore | pulse_graphics 渲染链：BeginFrame → ResetBackbuffer → PrepareWindows → RecordGraph（按 priority 升序调用所有 render record callback，最后 present 各窗口）→ ExecuteGraph → Submit → Present |
| EcsPostFrame | PulseWindowPostFrameSystem（窗口尺寸/标题同步，清除 PulseWindowResizedId）；PulseInputPostFrameClear（清空本帧瞬态输入） |

|------|------|

| `PulseAppDesc` | `name` + `enable_restapi`（开启后导入 flecs::stats / Rest） |
| `PulsePluginDesc` | 插件描述符：`name`、`ctx`、`build` / `post_build`（`PulseProcPluginBuildFn`）/ `shutdown`（`PulseProcPluginShutdownFn`） |

| `PulseProcRunnerFn` / `PulseProcSubappExtractFn` | 自定义主循环回调 / Subapp 帧前 extract 回调 |

### 生命周期与帧驱动

```
Created → Building（build 回调依次执行）→ PostBuilding（post_build 回调）→ Running → Shutdown
```

- `pulse_create_app` / `pulse_destroy_app`（析构走 teardown）
- `pulse_app_run` = `prepare()`（排空待注册插件 + post_build + 启动 Subapp）+ runner + `teardown()`
- 默认 runner 即循环 `pulse_app_update()`；可用 `pulse_app_set_runner` 替换（pulse_window 安装的 runner 即为自定义 runner）
- `pulse_app_update` = `world.progress()` 跑一帧 pipeline，然后依次对每个 Subapp 先调用其 extract 回调、再 `update()`
- `pulse_app_finish` / `pulse_app_should_quit` 控制退出
- Subapp：`pulse_app_insert_subapp` / `get_subapp` / `remove_subapp` / `pulse_app_set_subapp_extract`（每帧把提取数据复制到主世界）
- 工具：`pulse_app_world`、`pulse_app_has_plugin`、`pulse_app_last_error`、`pulse_get_app_from_world`

内部系统：`PulseTimeSystem`（EcsPreUpdate）每帧刷新 `PulseTimer` 单例。

| 项目 | 内容 |
|------|------|
| **职责** | SDL3 窗口管理：创建窗口、轮询 SDL 事件并转换为 ECS 事件、尺寸/标题同步 |
| **状态** | 已完成 |
| **头文件** | `src/pulse_window/include/pulse_window.h` |
| **依赖** | pulse_app、SDL3 |

| 组件/类型 | 说明 |
|-----------|------|
| `PulseWindow` | 窗口属性（title/width/height/resizable/external_graphics_context）；`on_set` hook 自动创建 SDL 窗口并补上 `PulseSdlWindow` |
| `PulseSdlWindow` | SDL 窗口句柄（`SDL_Window*`）、window_id、native_view（Win32 HWND / Android window） |
| `PulsePrimaryWindowId` | 标签，标记主窗口 |
| `PulseWindowCloseRequestedId` | 标签，收到关闭请求时打标（主窗口 + `EXIT_ON_PRIMARY_CLOSE` 时直接结束 app） |
| `PulseWindowResizedId` | 标签，尺寸变化时打标，PostFrame 清除 |

### 事件发射模型

`PulseWindowPluginDesc`（`PulseWindowPluginDesc`：`primary_window` + `flags` + `sdl_init_flags`）的 flags：

| Flag | 含义 |
|------|------|
| `PULSE_WINDOW_PLUGIN_CREATE_PRIMARY` | build 期创建主窗口 |
| `PULSE_WINDOW_PLUGIN_INSTALL_RUNNER` | 安装窗口 runner（每帧 poll SDL 事件 + update） |
| `PULSE_WINDOW_PLUGIN_EXIT_ON_PRIMARY_CLOSE` | 主窗口关闭即退出 |
| `PULSE_WINDOW_PLUGIN_DEFAULT` | 三者组合 |

默认窗口 1280×720、可缩放、`external_graphics_context = true`。窗口 runner 循环：

```
while (!pulse_app_should_quit(app)):
    SDL_PollEvent 全部事件 →
        QUIT → finish
        键盘/鼠标按键/滚轮 → 发射 PulseKeyEvent / PulseMouseButtonEvent / PulseMouseScrollEvent
        （事件类型定义在 pulse_input.h，供 pulse_input 消费）
        文本输入/焦点/悬停 → 发射 PulseTextInputEvent / PulseWindowFocusEvent / PulseWindowMouseHoverEvent
        关闭/尺寸变化 → 打标 PulseWindowCloseRequestedId / PulseWindowResizedId
    pulse_app_update(app)
```

这些事件通过 `ecs_enqueue` 以 ECS 事件形式发射，由各插件的 observer 响应。

### 系统

| 阶段 | 系统 | 行为 |
|------|------|------|
| EcsPostFrame | PulseWindowPostFrameSystem | 把组件里的尺寸/标题同步到 OS 窗口；清除 PulseWindowResizedId |

### API

```c
EPulseResult pulse_add_window_plugin(PulseAppId app, const PulseWindowPluginDesc* desc);
ecs_entity_t pulse_window_get_primary(PulseAppId app);
EPulseResult pulse_window_set_title(PulseAppId app, ecs_entity_t entity, const char* title);
void* pulse_window_get_native_view(PulseAppId app, ecs_entity_t entity);
```

添加 `PulseWindow` 组件的实体自动获得 `PulseSdlWindow`（`EcsWith`）。

| 项目 | 内容 |
|------|------|
| **职责** | 跨帧渐进式资源加载（按需推进加载队列）与生命周期管理（引用计数） |

| **头文件** | `src/pulse_asset/include/pulse_asset.h` |
| **依赖** | pulse_app |

| **PulseAssetRequest** | 异步加载请求（同样三件套），可轮询 `is_alive` / `is_ready` / `get_state` / `get_error` |
| **AssetState 状态机** | EMPTY → WAITING_LOAD → LOADING → WAITING_DEPENDENCIES → PROCESSING → LOADED / FAILED / PENDING_DELETE |
| **加载源** | 文件（`pulse_asset_system_load`）/ 内存（`load_from_memory`）/ Builder（`build` 异步、`build_sync` 同步） |
| **依赖解析** | 加载描述符里声明静态依赖（`PulseAssetDependency`：required/optional）；加载过程中可用 `pulse_asset_load_task_add_dependency` 动态追加，状态机自动进入 WAITING_DEPENDENCIES |

| **扩展机制** | `PulseAssetTypeDesc`（类型别名/销毁回调） + `PulseAssetLoaderDesc`（ctor/dtor/step 三步 loader，外加 settings 深拷贝回调） |

加载请求立即返回 `PulseAssetRequest`，由 **EcsOnLoad** 阶段的 AssetProcessSystem 逐帧推进加载队列（每帧最多处理 `max_requests_per_update` 个请求，默认 8，单线程顺序处理）。`PulseAssetPluginDesc` 含 `root_path`（默认 `"assets"`）。

## pulse_input ✅

| 项目 | 内容 |
|------|------|
| **职责** | 统一输入抽象层：把 SDL3 键盘/鼠标输入转化为 ECS 组件和事件 |
| **状态** | 已完成 |
| **头文件** | `src/pulse_input/include/pulse_input.h` |
| **依赖** | pulse_app + pulse_window（消费窗口发射的事件） |

### 输入模型

事件驱动为主：pulse_window 轮询 SDL 后发射 `PulseKeyEvent` / `PulseMouseButtonEvent` / `PulseMouseScrollEvent`，pulse_input 的 observer 响应事件更新单例组件；**仅鼠标 motion** 因为无事件源，保留在 `PulseInputSystem` 里直接轮询 SDL。

### ECS 组件（均为 Singleton）

```c
typedef struct PulseKeyboardInput {     // PULSE_SCANCODE_COUNT = 512
    bool pressed[512];                  // 按住状态
    bool just_pressed[512];             // 本帧新增按下（忽略 repeat）
    bool just_released[512];            // 本帧新增松开
} PulseKeyboardInput;

typedef struct PulseMouseInput {
    uint8_t state;                      // 按住按钮（位图）
    uint8_t just_pressed;               // 本帧新增按下
    uint8_t just_released;              // 本帧新增松开
} PulseMouseInput;

typedef struct PulseMouseMotion {
    float delta_x, delta_y;             // 帧累计相对增量（SDL 相对状态）
    float x, y;                         // 绝对位置
} PulseMouseMotion;

typedef struct PulseMouseScroll {
    float x, y;                         // 帧累计滚轮增量
} PulseMouseScroll;
```

### ECS 事件

```c
typedef struct PulseKeyEvent {
    int32_t  scancode;                  // 物理按键码
    int32_t  keycode;                   // 逻辑键码
    uint16_t mod;                       // 修饰键位
    bool     pressed, repeat;
    ecs_entity_t window;
} PulseKeyEvent;

typedef struct PulseMouseButtonEvent {
    uint8_t  button;                    // SDL_BUTTON_LEFT 等
    bool     pressed;
    float    x, y;
    bool     is_touch;
    ecs_entity_t window;
} PulseMouseButtonEvent;

typedef struct PulseMouseScrollEvent {
    float x, y;
    bool  is_touch;
    ecs_entity_t window;
} PulseMouseScrollEvent;
```

|------|------|------|

| EcsPreUpdate | PulseInputSystem | 轮询 SDL 鼠标位置/相对增量，更新 PulseMouseMotion |
| EcsPostFrame | PulseInputPostFrameClear | 清空 just_pressed / just_released / 滚轮增量，为下一帧做准备 |

## pulse_transform ✅

| 项目 | 内容 |
|------|------|
| **职责** | ECS 变换组件定义 + 层级关系管理（EcsChildOf）+ 变换传播系统 |
| **状态** | 已完成 |
| **头文件** | `src/pulse_transform/include/pulse_transform.h` |
| **依赖** | pulse_app + pulse_math |

### ECS 组件

```c
typedef struct PulseLocalTransform { HMM_Vec3 translation; HMM_Quat rotation; HMM_Vec3 scale; } PulseLocalTransform;  // 本地 TRS
typedef struct PulseWorldTransform { HMM_Mat4 value; } PulseWorldTransform;                                          // 层级传播结果
typedef struct PulseShowMatrix      { HMM_Mat4 model;  } PulseShowMatrix;                                            // 渲染用矩阵
```

`PulseLocalTransform` 直接存储 translation/rotation/scale（无独立 Position/Rotation/Scale 组件）。层级关系用 flecs 内建 `EcsChildOf`（自带 Acyclic、Exclusive、OnDeleteTarget=Delete 约束）。添加 `PulseLocalTransform` 时通过 `EcsWith` 自动附带 `PulseWorldTransform`。

### 系统

| 阶段 | 系统 | 行为 |
|------|------|------|
| EcsPostUpdate | EnsureWorldTransform | 修复有 LocalTransform 但缺 WorldTransform 的实体（如被手工 remove 过） |
| EcsPostUpdate | PropagateWorldTransform | 由 TRS 现场计算局部矩阵 T×R×S；查询项对父 WorldTransform 使用 `EcsCascade` 遍历 `(EcsChildOf, *)`，保证父先于子；根实体 world = local |

### API

```c
EPulseResult pulse_add_transform_plugin(PulseAppId app);

// 层级管理（薄封装 EcsChildOf）
void pulse_set_parent(PulseAppId app, ecs_entity_t child, ecs_entity_t parent);
void pulse_remove_parent(PulseAppId app, ecs_entity_t child);
ecs_entity_t pulse_get_parent(PulseAppId app, ecs_entity_t child);
```

### 插件描述符

`PulseGraphicsPluginDesc`：`backend`（默认 Vulkan）、`swapchain_format`（默认 R8G8B8A8_UNORM）、`image_count`（默认 3）、`enable_debug_layer`、`enable_gpu_based_validation`、`enable_vsync`、`record_callback`/`record_user_data`（插件级默认 record callback）、`per_draw_shader_property_count`/`p_per_draw_shader_properties`（每绘制项更新的 shader 属性名列表）。

### GPU 资源（Asset 化）

8 类资源均注册为 pulse_asset 类型（`PULSE_TYPE_*`），Handle/Request 成对出现，异步就绪：

| 类型 | 创建 / 加载 | 说明 |
|------|------------|------|
| ShaderLibrary | binary 同步 / 文件异步 | .spv 库 |
| Shader | binary 同步（vs+fs）/ 文件异步 | 绑定 blend/depth/rasterizer 状态 + 属性反射表 |
| ComputeShader | binary 同步 / 文件异步 | 计算着色器 |
| Mesh | data 同步（含顶点/索引布局）/ 文件异步（.obj 等） | `pulse_create_mesh_dynamic` 动态网格；`pulse_update_mesh_vertices/indices` 更新；支持 compute shader 更新数据 |
| Texture | 像素数据 / 图片文件 | mipmap 生成 |
| GraphicsBuffer | 描述符 + 初始数据 | uniform/storage 等 |
| Sampler | 描述符 | 采样器 |
| Material | 关联 Shader | Unity 风格属性设置：`pulse_material_set_property_float4/mat4/texture/sampler`（按名字）；`pulse_material_get_ubo_column` 读取 UBO 列；`pulse_material_get_shader` |

Shader 反射：`pulse_shader_get_shader_property_count/property`（`PulseShaderProperty`：name/type/role/set/binding/offset/size），`pulse_shader_get_ubo_info_count/info`（`PulseUboInfo`：layout_hash、material_managed、renderer_managed、per_draw 等）。

### ECS 组件

| 组件 | 说明 |
|------|------|
| `PulseRenderer` | 单例：cgpu instance/adapter/device/queue/render_pass、backend、swapchain_format、image_count、frame_index |
| `PulseSurface` | 窗口表面（挂窗口实体，`EcsWith` 链：PulseSdlWindow → PulseSurface → PulseSwapchain） |
| `PulseSwapchain` | 窗口交换链（backbuffer views/framebuffers/信号量、当前 backbuffer 等） |

### Rendergraph 封装

pulse_graphics 把 rendergraph（HGEGraphics）整体封装为 C API，每帧重建一个 graph：

- 资源声明/导入：`pulse_render_graph_declare_texture/buffer`、`import_texture/backbuffer/buffer/dynamic_buffer`、`declare_uniform_buffer_quick`、`declare_texture_subresource`；纹理/缓冲属性设置（extent/format/depth/size/type/usage）
- Pass：`add_render_pass` / `add_compute_pass` / `add_holdpass` / `add_uploadtexturepass(_ex)` / `add_uploadbufferpass(_ex)` / `add_generate_mipmap` / `pulse_render_graph_present` / `add_edge`
- RenderPass/ComputePass builder：attachment、sample、use_buffer(_as)、readwrite、set_executable
- Encoder：`pulse_render_pass_encoder_draw(_submesh/_procedure)`、`dispatch`、`set_global_texture/buffer/sampler(_handle/offset)`、viewport/scissor、`push_constants`、`resolve_buffer/texture_view`

### Record Callback 机制

```c
typedef struct PulseRenderRecordCallbackDesc {
    PulseProcRenderRecordCallback callback;  // (app, graph, user_data)
    void* user_data;
    int32_t priority;                        // 小者先执行
} PulseRenderRecordCallbackDesc;
```

`pulse_add_render_record_callback` / `pulse_remove_render_record_callback`。内置注册：上传 pass 优先级 -1000，pulse_renderer 100，用户自定，pulse_imgui 10000（最后叠加）。

### 每帧渲染链（EcsOnStore 下的自定义 phase 链）

```
PulseCgpuRenderBeginFrame    等待帧 fence、重置命令池/执行上下文、标记帧激活
  → PulseCgpuRenderResetBackbuffer  清空所有 swapchain 的 current_backbuffer
  → PulseCgpuRenderPrepareWindows   确保窗口 surface/swapchain，acquire 下一张 backbuffer
  → PulseCgpuRenderRecordGraph      按 priority 升序调用所有 record callback，最后对每个窗口 present
  → PulseCgpuRenderExecuteGraph     rendergraph 编译 + 执行（提交到命令缓冲）
  → PulseCgpuRenderSubmit           cgpu_queue_submit（含 acquire/render 信号量、帧 fence）
  → PulseCgpuRenderPresent          对每个窗口 cgpu_queue_present
```

内置资源：blit shader（.spv 内嵌）+ 线性采样器（用于 present/mipmap）、默认纹理/采样器/缓冲。

```c
typedef struct PulseRenderable {
    PulseMeshHandle mesh;
    PulseMaterialHandle material;
} PulseRenderable;
```

### 着色器属性映射

`EPulseRendererPropertyType`：`VP_MATRIX`（默认映射 shader 属性名 `"vpMatrix"`）、`MODEL_MATRIX`（默认 `"wMatrix"`）；`pulse_set_shader_property_name_mapper` 可改映射。默认每绘制项属性列表为 `["wMatrix"]`（`pulse_set_per_draw_shader_properties`）。shader 里 role 为 NON_MATERIAL 且名字匹配的属性，由 renderer 每帧写入 renderer 管理的 UBO。

### 系统（EcsPostUpdate，依赖 PropagateWorldTransform）

| 系统 | 行为 |
|------|------|
| PulseRendererExtractCameras | 遍历 Camera + WorldTransform：构建 view/proj 矩阵（LH 透视、fov 弧度转换），宽高取自关联窗口；写入写包（双缓冲） |
| PulseRendererCollectRenderables | 遍历 Renderable + WorldTransform：生成 RenderObject（sort_key = shader<<48 \| material<<32 \| mesh），加入所有 view（v0.1 无视锥剔除） |
| PulseRendererSortAndPack | 每个 view 按 sort_key 排序 |
| PulseRendererPacketsSwap | 交换读写双缓冲，清写包、回收 UBO 缓存 |

### Record Callback（post_build 注册，priority = 100）

`record_renderer_callback` 按 view 执行：

1. `pulse_import_window_backbuffer` 导入窗口 backbuffer
2. 为每个 renderer 管理的 UBO 构建列：per-draw 属性（vp/w 矩阵）写入、非 per-draw 按 layout_hash + material 缓存复用；从 GPU block 池分配（UBO 对齐来自 adapter 查询）
3. 创建 pass `RendererView_<camera>`（黑色 clear + store），注册使用的 UBO buffer
4. executable：为每个对象 set UBO 列（`set_global_buffer_offset`）后 `pulse_render_pass_encoder_draw`

## pulse_daslang ✅

| 项目 | 内容 |
|------|------|
| **职责** | DaScript 脚本运行时管理：VM 初始化、模块路径管理、脚本加载与执行、以及随插件内建的 ECS/数学/GPU 绑定层 |
| **状态** | 已完成 |
| **头文件** | `src/pulse_daslang/include/pulse_daslang.h` |
| **依赖** | pulse_app + libDaScript（+ flecs、cgpu 绑定） |

> 说明：DaScript 运行时管理与绑定层统一实现在本插件内；脚本接入模型为「加载 .das 模块，调用脚本导出的 `importModule` 注册 ECS 内容」。

### 职责范围

- DaScript 环境初始化：`need_das_modules()`（NEED_ALL_DEFAULT_MODULES + ModuleFlecs/ModuleCGPU/ModulePulse）+ `das::Module::Initialize()`，进程内只做一次
- 模块路径管理：`PulseDaslangPluginDesc.root_path` 为脚本根目录，加载时额外注册 `addFsRoot("pulse", root_path/pulse)`，脚本内 `require pulse/<module>` 可引用共享模块
- 脚本加载：`pulse_load_module(app, script_path)` 编译 + simulate 脚本，要求脚本导出 `def importModule(var ctx: ModuleContext): void`，调用后由脚本内的 `[system]`/组件注册宏把游戏模块注册进 ECS 世界，随主循环运行
- 每个已加载模块持有自己的 ModuleGroup / Program / Context（模块间互不干扰）；插件 shutdown 时清空

### 脚本侧 ModuleContext

```c
struct ModuleContext {                    // dasPulseECS::ModuleContext
    World world;                          // 包装 ecs_world_t*
    ecs_entity_t initPipeline;            // EcsOnStart
    ecs_entity_t updatePipeline;          // EcsOnUpdate
    ecs_entity_t postUpdatePipeline;      // EcsPostUpdate
    ecs_entity_t renderPipeline;          // EcsOnStore
    ecs_entity_t imguiPipeline;           // PulseImguiPhase（pulse_imgui_get_phase）
};
```
