# v0.1 插件设计

本文定义 v0.1 每个 pulse_* 插件的职责、ECS 组件、系统和依赖关系。

---

## IDL 代码生成

所有 pulse_* 插件的 C API 头文件均通过 IDL（接口定义语言）自动生成。处理流程与语法详见 [`docs/IDL.md`](../IDL.md)。


## pulse_input 🆕

| 项目 | 内容 |
|------|------|
| **职责** | 统一输入抽象层，将 SDL3 键盘/鼠标的原始输入转化为 ECS 组件和事件 |
| **状态** | 待实现 |
| **头文件** | `src/pulse_input/include/pulse_input.h` |
| **依赖** | pulse_app + pulse_window |

### ECS 组件（均为 Singleton）

```cpp
struct PulseKeyboardInput {
    uint8_t pressed[SDL_SCANCODE_COUNT / 8 + 1];       // 按住状态（位图）
    uint8_t just_pressed[SDL_SCANCODE_COUNT / 8 + 1];  // 本帧新增按下
    uint8_t just_released[SDL_SCANCODE_COUNT / 8 + 1]; // 本帧新增松开
};

struct PulseMouseInput {
    uint8_t state;           // 按住按钮（位图）
    uint8_t just_pressed;    // 本帧新增按下
    uint8_t just_released;   // 本帧新增松开
};

struct PulseMouseMotion {
    float delta_x, delta_y;  // 帧累计增量
    float x, y;              // 绝对位置
};

struct PulseMouseScroll {
    float x, y;              // 帧累计滚轮增量
};
```

### ECS 事件

```cpp
struct PulseKeyEvent {
    SDL_Scancode scancode;   // 物理按键码
    SDL_Keycode sym;         // 逻辑键码
    bool pressed, repeat;
    ecs_entity_t window;
};

struct PulseMouseButtonEvent {
    uint8_t button;          // SDL_BUTTON_LEFT 等
    float x, y;
    bool pressed;
    ecs_entity_t window;
};
```

### 系统

| 阶段 | 系统 | 行为 |
|------|------|------|
| EcsPreUpdate | PulseInputSystem | 轮询 SDL 输入，更新 PulseKeyboardInput / PulseMouseInput / PulseMouseMotion / PulseMouseScroll，发射 PulseKeyEvent / PulseMouseButtonEvent |

### API

```c

bool pulse_input_key_just_pressed(PulseAppId app, SDL_Scancode scancode);
bool pulse_input_key_just_released(PulseAppId app, SDL_Scancode scancode);
```

## pulse_transform 🆕

| 项目 | 内容 |
|------|------|
| **职责** | ECS 变换组件定义 + 层级关系管理 + 变换传播系统 |
| **状态** | 已实现（基础） |
| **头文件** | `src/pulse_transform/include/pulse_transform.h` |
| **依赖** | pulse_app + pulse_math |

### ECS 组件

```cpp
struct PulsePosition     { HMM_Vec3 value; };
struct PulseRotation     { HMM_Quat value; };
struct PulseScale        { HMM_Vec3 value; };           // 本地缩放
struct PulseLocalTransform  { HMM_Mat4 model; };        // 由 Position/Rotation/Scale 计算得出
struct PulseWorldTransform  { HMM_Mat4 value; };        // 由层级传播计算得出
struct PulseShowMatrix   { HMM_Mat4 model; };           // 插值后的渲染用矩阵
```

层级关系通过 Flecs 内建的 `EcsChildOf` 关系表达，无需额外的 Tree 组件。`EcsChildOf` 自带 Acyclic（无环）、Exclusive（单父）、OnDeleteTarget=Delete（父删子删）等约束。

添加任意 TRS 输入组件时，通过 `EcsWith` 自动附带 `PulseLocalTransform` 和 `PulseWorldTransform`。

### 系统

| 阶段 | 系统 | 行为 |
|------|------|------|
| PostUpdate | UpdateLocalTransform | 有 Position（+ 可选 Rotation/Scale）时计算 LocalTransform = T × R × S |
| PostUpdate | PropagateWorldTransform | 遍历有 LocalTransform + WorldTransform 的实体，沿 EcsChildOf 向上查父 WorldTransform，计算 world = parent_world × local |

### API

```c
EPulseResult pulse_add_transform_plugin(PulseAppId app);

// 层级管理（薄封装 EcsChildOf）
void pulse_set_parent(PulseAppId app, ecs_entity_t child, ecs_entity_t parent);
void pulse_remove_parent(PulseAppId app, ecs_entity_t child);
ecs_entity_t pulse_get_parent(PulseAppId app, ecs_entity_t child);
```

## pulse_renderer 🆕

| 项目 | 内容 |
|------|------|
| **职责** | 高层渲染管线框架：封装从 ECS 世界到 GPU 渲染的完整流程 |
| **状态** | 待实现 |
| **头文件** | `src/pulse_renderer/include/pulse_renderer.h` |
| **依赖** | pulse_app + pulse_math + pulse_graphics + pulse_transform + pulse_asset |

### ECS 组件

```cpp
struct Camera {
    ecs_entity_t window_entity;
    float fov, nearPlane, farPlane;
    int width, height;
};
struct Light {
    HMM_Vec4 color;
};
struct Renderable {
    PulseMeshHandle mesh;
    PulseMaterialHandle material;
};
```

### API

```c
// 注册默认渲染管线
EPulseResult pulse_add_renderer_plugin(PulseAppId app, ...);

// 渲染数据包（内部使用）
struct PulseRenderPacket { ... };   // 封装帧数据包
```

### 渲染流程

```
每帧：
  1. simulate  → 更新游戏逻辑（用户 system）
  2. interpolate → 运行 RenderPipeline（计算插值 + ShowMatrix）
  3. extract   → 遍历 Camera，收集可视 Renderable，构建 RenderPacket
  4. submit    → 遍历 RenderPacket，提交到 rendergraph 的 pass
```

具体实现使用 pulse_graphics 的 `AddRenderRecordCallback` 注册回调，在 RenderGraph 构建阶段执行 submit。

### API

```c
typedef void (*PulseProcImGuiDrawFn)(void* user_data);

EPulseResult pulse_add_imgui_plugin(PulseAppId app, ...);
EPulseResult pulse_imgui_add_draw_callback(PulseAppId app,
    PulseProcImGuiDrawFn callback, void* user_data, int priority);
```

- 在 pulse_window 的渲染流程末尾插入一个高优先级（如 1000）的 record callback

## pulse_dascript_binding 🆕

| 项目 | 内容 |
|------|------|
| **职责** | 各 pulse 模块类型和函数到 DaScript 的 binding 注册 |
| **状态** | 待实现 |
| **头文件** | `src/pulse_dascript_binding/include/pulse_dascript_binding.h` |
| **依赖** | pulse_app + pulse_script_dascript + 各绑定的 pulse 模块 |

### 设计

所有 binding 代码集中放在 `pulse_dascript_binding` 模块下：

```
src/pulse_dascript_binding/
├── include/
│   └── pulse_dascript_binding.h     ← 统一注册入口
└── src/
    ├── pulse_math_das.cpp           ← 注册 HMM_Vec3, HMM_Quat, HMM_Mat4 等数学类型
    ├── pulse_transform_das.cpp      ← 注册 Position, Rotation, Scale, LocalTransform, WorldTransform 等
    ├── pulse_renderer_das.cpp       ← 注册 Camera, Light, Renderable 等
    ├── pulse_asset_das.cpp          ← 注册 AssetHandle 等
    └── pulse_graphics_das.cpp       ← 注册 ShaderHandle, MeshHandle, TextureHandle 等 GPU 句柄
```

`pulse_dascript_binding` 在 build 阶段依次调用各内部模块的注册函数，`pulse_script_dascript` 不关心具体注册了哪些类型。
